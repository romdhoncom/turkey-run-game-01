Gobble Dash — Turkey's Great Escape: a complete, original 2D canvas turkey escape game. Gus the turkey flees Farmer Bram across the farmyard, through the barn and into the kitchen, jumping fences and ovens, ducking under hay bales, hiding in haystacks, and dodging falling carving knives — 1000 metres to the woods and freedom. Keyboard and mouse, static files, no network, synthesized WebAudio sounds.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080 in desktop Chrome
```
